<h2> KPI Dashboard Tracker </h2>
<br>
Identified a recurring manual bottleneck where engineers cross-checked two weekly S360 Excel exports by hand to track resolved, overdue, near-due, and ETA-changed KPIs, and independently designed
<br>
Built <b>KPI Dashboard Tracker</b> — a browser-based HTML/CSS/JavaScript tool that automates the comparison, classifies KPIs by status change, and presents results through an interactive dashboard with summary cards and an executive summary view, replacing the manual process.
